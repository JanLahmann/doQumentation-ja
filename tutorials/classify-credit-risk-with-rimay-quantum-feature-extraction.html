Kipu QuantumのRimay Quantum Feature Extractionによる信用リスクの分類

備考

Qiskit Functionsは、IBM Quantum® Premium Plan、Flex Plan、On-Prem(IBM Quantum Platform API経由)Planのユーザーのみが利用できる実験的な機能です。プレビューリリースの状態であり、変更される可能性があります。

使用量の目安: Nighthawk r2プロセッサーで2分。(注: これはあくまで目安です。実際の実行時間は異なる場合があります。)

学習目標​

  • カテゴリー列と数値列を含む表形式データを、Rimay Qiskit Functionのために準備する。

  • 訓練データで量子特徴マッピングをフィットし、同じ実行でテストデータをマッピングする。

  • 量子変換された特徴量だけの場合と、元の特徴量と組み合わせた場合とで、古典モデルを訓練する。

  • 結果を純粋に古典的なベースラインと比較する。

前提条件​

このチュートリアルを始める前に、以下のトピックに慣れておく必要があります。

  • Qiskit Functionsの紹介

  • scikit-learnによる教師あり分類

背景​

産業界の多くの機械学習の問題は、小規模から中規模の表形式データセットを扱い、データを追加することができず、モデルの精度が頭打ちになります。信用リスクのスコアリングはその典型例です。貸し手は数十の属性を使って、申込者が与信を返済しそうかどうかを判断します。

Kipu QuantumのQiskit FunctionであるRimayは、このようなパイプラインに量子前処理のステップを追加します。これは、デジタル化された反断熱量子特徴抽出アルゴリズム [1] を実装しています。各入力特徴量は1つの量子ビットにマッピングされます。特徴量の値と特徴量間の相互情報量が、スピングラス・ハミルトニアンの局所場とカップリングを決めます。続いて反断熱ダイナミクスが量子系を低エネルギー状態へと発展させ、最後に測定される1体および2体の期待値が、新しい量子変換された特徴量になります。これらの特徴量は入力間の非線形な相関を捉えており、任意の古典モデルに入力できます。

このチュートリアルでは、OpenMLのドイツ信用データセット [2](申込者1000人、属性20個)を使って、ランダムフォレスト分類器を訓練します。まず古典的なベースラインを確立し、次にデータをRimayに送り、最後に量子変換された特徴量だけの場合と、元の特徴量と組み合わせた場合とで、同じ種類のモデルを訓練します。

def train_random_forest(x, y, n_estimators, max_depth):
    """Train a random forest classifier with fixed hyperparameters."""
    model = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        min_samples_split=5,
        min_samples_leaf=1,
        max_features="sqrt",
        random_state=42,
        n_jobs=-1,
    )
    return model.fit(x, y)

def evaluate(model, x, y):
    """Return the classification metrics of a trained model on a test set."""
    y_pred = model.predict(x)
    y_proba = model.predict_proba(x)[:, 1]
    return {
        "Accuracy": accuracy_score(y, y_pred),
        "AUC": roc_auc_score(y, y_proba),
        "F1 score": f1_score(y, y_pred),
        "Precision": precision_score(y, y_pred),
        "Recall": recall_score(y, y_pred),
    }

ステップ 2: 量子ハードウェアでの実行に向けて問題を最適化する​

Rimay は選択したプロセッサー向けに回路を構築してトランスパイルするため、手動で最適化する回路はありません。次の制約の範囲内で、回路ごとのショット数を指定します。

  • 各特徴量に量子ビットが1つ必要なので、プロセッサーにはデータセットの特徴量数以上の量子ビット数が必要です。

  • Rimay は、学習行とテスト行を合わせて、行ごとに1つの回路を実行します。1つのジョブで要求できる実行回数は最大1,000万回なので、行数に shots を掛けた値がこの上限内に収まる必要があります。

ジョブを送信する前に、両方の制限を確認してください。

備考

ジョブは、回路がキューで待機する時間も含めて24時間以内に完了する必要があります。そうでない場合、結果が得られないまま停止されます。

関数サイズを計算する​

すべてのジョブは、S、M、L のいずれかの関数サイズで実行され、実行に使用される計算リソースが決まります。Rimay の場合、サイズはジョブがマッピングする行数(学習行とテスト行の合計)によって決まります。小さすぎるサイズを要求すると、ジョブはエラー 4600 で失敗します。サイズとその制限については、Rimay ガイドの関数サイズを参照してください。

次のセルでは、サイズ計算ツールを定義します。これはお使いのマシン上で実行され、渡したデータのみを読み取り、何も送信しません。

from os import PathLike
from typing import Any, Literal, Sequence, Sized

Size = Literal["S", "M", "L"]

# Upper bounds (inclusive) in samples.
_SMALL = 2_999
_MEDIUM = 9_999

FIT_TRANSFORM, TRANSFORM, DELETE = "fit-transform", "transform", "delete"

# Which positions of input_file hold samples, per mode. The labels in
# y_train submit no circuits of their own, so they are not counted.
SAMPLE_POSITIONS = {FIT_TRANSFORM: (0, 2), TRANSFORM: (0,)}

def calculate_function_size(problem: Sequence[Sized], **kwargs: Any) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    metrics = _measure(problem, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def _measure(problem: Sequence[Sized], **kwargs: Any) -> dict:
    """The samples the job submits."""
    return {"samples": count_samples(problem, kwargs.get("mode"))}

def count_samples(problem: Sequence[Sized], mode: Any) -> int:
    """Rows across the data sets of ``problem`` that carry samples."""
    if mode == DELETE:
        return 0
    if mode not in SAMPLE_POSITIONS:
        raise ValueError(f"cannot size mode {mode!r}")
    if _is_name(problem) or (
        isinstance(problem, (list, tuple))
        and any(_is_name(data) for data in problem)
    ):
        raise TypeError(
            "pass the data, not the file name: read each input_file, e.g. with "
            "pandas.read_csv, and pass the data sets in input_file order"
        )
    if not isinstance(problem, (list, tuple)):
        raise TypeError(
            "pass a list of data sets in input_file order, e.g. [x_train, y_train], "
            f"not a single {type(problem).__name__}"
        )
    return sum(
        len(problem[i]) for i in SAMPLE_POSITIONS[mode] if i < len(problem)
    )

def _is_name(value: Any) -> bool:
    """A file name or path rather than data."""
    return isinstance(value, (str, bytes, PathLike))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return metrics["samples"] <= _SMALL

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return metrics["samples"] <= _MEDIUM

input_file のファイルと同じ順序でデータセットを、実行モードとともに渡します。

size = calculate_function_size(
    [x_train, y_train, x_test], mode="fit-transform"
)
print(size)

ステップ 3: Qiskit primitives を使用して実行する​

Rimay を fit-transform モードで実行します。x_train.csv と y_train.csv で量子特徴量マッピングを適合させ、そのマッピングで学習セットとテストセットの両方をマッピングします。input_file 内のファイルの順序は重要です。学習用特徴量、学習用ラベル、そして任意のテスト用特徴量の順に指定してください。計算したサイズを function_size として渡します。

job = rimay.run(
    mode="fit-transform",
    input_file=[
        "x_train.csv",
        "y_train.csv",
        "x_test.csv",
    ],  # This order matters
    backend_name=backend.name,
    shots=shots,
    function_size=size,
)
print(job.job_id)

AUC は、判定しきい値に依存せず、モデルが良好なクレジットを不良なクレジットより上位に順位付けできる度合いを測る指標で、この不均衡なデータセット(良好なクレジットが70%)で最も有益な指標です。Kipu Quantum のベンチマークでは、量子変換された特徴量だけでも古典的なベースラインと同程度の AUC に達し、両方を組み合わせたハイブリッドモデルが最も高い AUC と F1 スコアに達しました。したがって、量子変換された特徴量は、古典的な特徴量だけでは得られない情報を加えていることになります。

まとめ​

達成したこと​

このチュートリアルでは、次のことを達成しました。

  1. 量子特徴抽出のために、カテゴリ属性と数値属性を持つ実世界のクレジットリスクデータセットを準備しました。

  2. 古典的なランダムフォレストのベースラインを確立しました。

  3. Rimay を使用して量子ハードウェア上で量子特徴マッピングを適合させ、1回の実行で学習セットとテストセットをマッピングしました。

  4. 量子変換された特徴量と結合した特徴量で同じモデルを学習し、ベースラインと比較しました。

重要なポイント​

  • Rimay は、追加の前処理ステップ1つとして、既存の機械学習パイプラインに組み込めます。データ準備と古典的なモデルはそのまま使えます。

  • 量子ビットの数が入力特徴量の数の上限を決め、行数に shots を掛けた値が1つのジョブのサイズの上限を決めます。

  • モデルが両方を活用できるため、量子変換された特徴量を元の特徴量と組み合わせて使用することをデフォルトにしてください。

次のステップ​

おすすめ
  • Rimay ガイドを読んで、すべての入力について学び、mode="transform" で新しいデータをマッピングし、さらなるベンチマークを確認してください。
  • 量子特徴抽出が衛星画像分類にどのように適用されたかについては、[3]をお読みください。
