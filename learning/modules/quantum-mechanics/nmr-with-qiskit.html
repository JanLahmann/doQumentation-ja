Qiskit による核磁気共鳴

この Qiskit in Classrooms モジュールでは、学生は次のパッケージがインストールされた動作する Python 環境を用意する必要があります。

  • qiskit v2.1 以降
  • qiskit-ibm-runtime v0.40.1 以降
  • qiskit-aer v0.17 以降
  • scipy と matplotlib(フィッティングとプロットのため)
  • pylatexenc(回路図のレンダリングのため)

上記のパッケージをセットアップしてインストールするには、Install Qiskit ガイドを参照してください。実際の量子コンピューターでジョブを実行するには、Set up your IBM Cloud® account ガイドの手順に従って、学生が IBM Quantum® のアカウントを設定する必要があります。

このモジュールはテスト済みで、QPU 時間を約 5 分使用します。これは見積もりであり、実際の使用量は異なる場合があります。

はじめに​

化学者が NMR 実験を行うとき、核スピンの試料を強い磁場の中に置き、ラジオ波(RF)パルスを印加して、返ってくる信号を測定します。この手法は、磁場中のスピン 1/2 粒子の量子力学に由来するいくつかの考え方に基づいています。スピンには 2 つのエネルギー準位があり、その間隔は特徴的なラーモア周波数に対応するエネルギーで隔てられています。その周波数での共鳴パルスはスピンを横平面に倒し、そこでスピンは歳差運動して信号を誘起し、その信号は 2 つの特徴的な時間 T1T_1T1​ と T2T_2T2​ で減衰していきます。

超伝導キュービットは、これと同じ対象を人工的に作り出したものであり、制御可能な 2 準位の量子系です。その ∣0⟩|0\rangle∣0⟩ 状態と ∣1⟩|1\rangle∣1⟩ 状態はスピンアップとスピンダウンに相当し、回転させるために適用するゲートは RF パルスに相当し、独自の T1T_1T1​ と T2T_2T2​ でコヒーレンスを失います。これは単なる大まかな比較ではありません。1990 年代後半から 2000 年代初頭にかけての最初期の実験的な量子プロセッサの一部は、NMR を使用していました。

このモジュールでは、実際の量子コンピューターを使用して、NMR 分光学者(またはハードウェアを較正する量子エンジニア)が行うのと同じ特性評価実験を実行します。

  • Rabi / 章動 — スピンを駆動し、それが回転する様子を観察します。これが π\piπ または π/2\pi/2π/2 回転を較正する方法です。

  • T1T_1T1​ — スピン-格子緩和。励起されたスピンが平衡状態に戻る減衰です。

  • T2T_2T2​ — スピン-スピン緩和(位相緩和)。Ramsey 実験で測定し、Hahn エコーで再収束させます。

  • NMR 分光(化学シフトと JJJ カップリング) — 複数のキュービット上で小さな分子をシミュレーションし、その多重線スペクトルを読み取って、n+1n+1n+1 則によって結合の接続関係を復元します。

各概念について、まず最小限の理論を示し、その後、4 段階の Qiskit patterns ワークフローに従って Qiskit で実験を実装します。

理論​

磁場中のスピン 1/2 粒子​

スピン 1/2 の原子核は磁気モーメント μ=γℏI\boldsymbol{\mu} = \gamma \hbar \mathbf{I}μ=γℏI を持ちます。ここで γ\gammaγ は磁気回転比です。zzz 方向の静磁場 B0B_0B0​ の中では、2 つのスピン状態はエネルギーが分裂します(Zeeman 効果)。

E±=∓12γℏB0,ΔE=γℏB0=ℏω0.E_{\pm} = \mp \tfrac{1}{2}\gamma \hbar B_0, \qquad \Delta E = \gamma \hbar B_0 = \hbar \omega_0 .E±​=∓21​γℏB0​,ΔE=γℏB0​=ℏω0​.

このエネルギー差がラーモア(共鳴)周波数 ω0=γB0\omega_0 = \gamma B_0ω0​=γB0​ を定めます。磁気モーメントは、この同じ周波数で B0B_0B0​ の周りを歳差運動します。

スピンを回転させるには、ω0\omega_0ω0​ またはその近傍で振動する RF 磁場を印加します。駆動周波数で回転する座標系(回転座標系)では、共鳴駆動は Bloch ベクトルを xxx-yyy 平面内の軸の周りに回転させます。どれだけ回転するか(フリップ角)は、パルスの強さと持続時間で決まります。特に重要な選択は 2 つあります。90∘90^\circ90∘ パルスは +1/2+1/2+1/2 のスピンを横平面に倒し、180∘180^\circ180∘ パルスはそれを完全に −1/2-1/2−1/2 に回転させます。

NMR とクォンタム・コンピューティングの用語の対応​

キュービットは 2 準位系であり、数学的には磁場中のスピン 1/2 と同一です — したがって、原子核ではなく量子プロセッサ上で実行していても、その物理は NMR の根底にある物理と同じです。異なるのは用語だけです。この表は、物理化学者とクォンタム・コンピューティングの専門家の双方と話をする助けになります。

import numpy as np
from itertools import combinations
from qiskit_aer import AerSimulator
from qiskit.transpiler import generate_preset_pass_manager
from qiskit_ibm_runtime import EstimatorV2 as Estimator

USE_HARDWARE = True  # <-- set True to run on the QPU selected above
USE_BATCH = False  # Safer for a class with pauses; set True for an uninterrupted run

if USE_HARDWARE:
    run_backend = backend  # the real QPU selected above
else:
    # Local testing mode: an Aer simulator that mimics the selected device -- its noise model,
    # coupling map, and qubit count -- while layout choices still use real calibration data.
    run_backend = AerSimulator.from_backend(backend)

# --- Choose connected qubits with low readout error. --------------------------------------
def readout_error(q):
    props = backend.target["measure"].get((q,))
    return props.error if props is not None and props.error is not None else 1.0

coupling_map = backend.coupling_map or backend.target.build_coupling_map()
edges = {tuple(sorted(edge)) for edge in coupling_map.get_edges() if edge[0] != edge[1]}

# AX needs one connected pair.
AX_LAYOUT = list(min(edges, key=lambda edge: sum(readout_error(q) for q in edge)))

# AX2 needs one qubit connected to two neighbours; the first entry is the central A qubit.
neighbors = {q: set() for q in range(backend.num_qubits)}
for q0, q1 in edges:
    neighbors[q0].add(q1)
    neighbors[q1].add(q0)
ax2_layouts = (
    [a, x1, x2]
    for a, adjacent in neighbors.items()
    for x1, x2 in combinations(adjacent, 2)
)
AX2_LAYOUT = min(ax2_layouts, key=lambda layout: sum(readout_error(q) for q in layout))

# Use a long-lived qubit for the single-qubit experiments.
def best_qubit(backend):
    return max(
        range(backend.num_qubits), key=lambda q: backend.qubit_properties(q).t2 or 0.0
    )

QUBIT = best_qubit(backend)
qp = backend.qubit_properties(QUBIT)
print(
    f"Using qubit {QUBIT} for single-qubit experiments: "
    f"T1 = {qp.t1 * 1e6:.0f} us, T2 = {qp.t2 * 1e6:.0f} us"
)
print(f"Using physical qubits {AX_LAYOUT} for AX")
print(f"Using physical qubits {AX2_LAYOUT} for AX2 (A first, then the two X spins)")

pm_q = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=[QUBIT]
)
pm_ax = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX_LAYOUT
)
pm_ax2 = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX2_LAYOUT
)

# Job mode is the default because a classroom pause can deactivate a Batch. On the Open plan,
# a Batch has a 10-minute maximum lifetime and deactivates after 1 minute with no queued job.

sampler = Sampler(mode=execution_mode)
estimator = Estimator(mode=execution_mode)
estimator.options.resilience_level = 0  # raw expectation values, no error mitigation
estimator.options.default_shots = 1000

mode_name = "Batch" if USE_BATCH else "individual jobs"

print(f"Ready. Running on {device_name} using {mode_name}.")

実験:Rabi 振動(章動)​

理論​

スピンを共鳴で駆動すると、その Bloch ベクトルは極から極へ一定に回転します — 章動します。∣0⟩|0\rangle∣0⟩ から始まるキュービットに、xxx 軸の周りにフリップ角 θ\thetaθ の回転を適用すると、∣1⟩|1\rangle∣1⟩ に見いだされる確率は次のとおりです。

P1(θ)=sin⁡2 ⁣(θ2)=12(1−cos⁡θ).P_1(\theta) = \sin^2\!\left(\tfrac{\theta}{2}\right) = \tfrac{1}{2}\bigl(1 - \cos\theta\bigr).P1​(θ)=sin2(2θ​)=21​(1−cosθ).

これが Rabi 曲線です。その最初の極大が π\piπ パルス(完全反転、180∘180^\circ180∘ パルス)です。π/2\pi/2π/2 パルスは 4 分の 1 回転(スピンを横平面に倒す 90∘90^\circ90∘ パルス)です。NMR では、この曲線がパルスを較正する方法です。

実験上の注意

文字どおりの Rabi 実験では、駆動の振幅または持続時間を時間方向に掃引します。そのためにはパルスレベルの制御が必要ですが、これは Qiskit v2.0 で削除されました。ここでは代わりに、RX(θ)R_X(\theta)RX​(θ) ゲートの回転角 θ\thetaθ を掃引します。曲線と π\piπ/π/2\pi/2π/2 の対応は同一です。唯一の違いは、パルス長を較正する代わりに、角度を直接選ぶことです。分数ゲートを備えたハードウェアでは、任意の θ\thetaθ に対する RX(θ)R_X(\theta)RX​(θ) がネイティブに実行されます。

Bloch 球での見方​

以下のアニメーションは章動を示しています。共鳴駆動が Bloch ベクトルを xxx 軸の周りに一定に回転させ、∣0⟩|0\rangle∣0⟩ から ∣1⟩|1\rangle∣1⟩ の方へ下り、また戻ります。これはまさに Rabi 曲線が測定している動きです。

問題を回路にマッピングする​

パラメータ化された回路を 1 つ構築します。RX(θ)R_X(\theta)RX​(θ) に測定が続く回路で、後で多数の角度で一度に評価します。

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

theta = Parameter("theta")
rabi = QuantumCircuit(1, 1)
rabi.rx(theta, 0)
rabi.measure(0, 0)
rabi.draw("mpl")

実行のための最適化​

選択したバックエンド向けの命令セットアーキテクチャ(ISA)回路にトランスパイルします。

rabi_isa = pm_q.run(rabi)

実行​

θ\thetaθ を 000 から 4π4\pi4π まで(Rabi サイクル 2 周分)掃引します。パラメータ値の配列を 1 つの Primitive Unified Bloc(PUB)として渡すと、それらすべてを 1 つのジョブで実行します。

angles = np.linspace(0, 4 * np.pi, 41)
job = sampler.run([(rabi_isa, angles.reshape(-1, 1))], shots=1000)
rabi_result = job.result()

理解度チェック​

測定した曲線では、P1P_1P1​ は π\piπ パルス(θ=π\theta = \piθ=π)で最初に最大値に達します。ここで、あるデバイスが誤較正されていて、x 軸上の公称角度 θ\thetaθ が実際には 1.05 θ1.05\,\theta1.05θ の回転を生じると仮定します。

(a) P1P_1P1​ の最初の極大は、公称角度がいくつのところに現れますか。 (b) 単一の π\piπ パルスを適用することは、この 5% の誤差を検出する感度の高い方法でしょうか。

解答

(a) 極大は実際の回転が π\piπ に等しくなるところ、つまり公称角度 θ=π/1.05≈0.95π\theta = \pi/1.05 \approx 0.95\piθ=π/1.05≈0.95π に現れます — ピークがわずかに左へシフトします。

(b) いいえ。公称 π\piπ パルスは実際には 1.05π1.05\pi1.05π の回転を生じ、P1=sin⁡2(1.05π/2)≈0.994P_1 = \sin^2(1.05\pi/2) \approx 0.994P1​=sin2(1.05π/2)≈0.994 となり、111 にはなりません — 測定ノイズに対して見分けるには小さすぎる変化です。このため、正確に較正するには、NMR 分光学者は回転を何度も適用して(たとえば 360∘360^\circ360∘ 法や長いパルス列)誤差を増幅します。これにより、パルスごとの小さな誤差が蓄積して、測定可能な大きなずれになります。この考え方は、チャレンジ問題で再び取り上げます。

実験:T1T_1T1​(スピン-格子緩和)​

理論​

励起されたスピンは、放置するとそのエネルギーを周囲(「格子」)に放出し、熱平衡へと緩和していきます。励起状態の占有率は、スピン-格子緩和時間 T1T_1T1​ で指数関数的に減衰します。

P1(τ)=e−τ/T1.P_1(\tau) = e^{-\tau/T_1}.P1​(τ)=e−τ/T1​.

化学者にとって、T1T_1T1​ は定量NMRでスキャンの間に待つ必要があるリサイクル遅延を決めるものであり、分子のタンブリングや動力学についての情報も与えてくれます。量子ビットでは、これはエネルギー緩和時間であり、量子コンピューターにおけるデコヒーレンスの影響をモデル化するために使われる2つの主要な数値のうちの1つです。

実験の手順。 XXX ゲート(π\piπ パルス)で ∣1⟩|1\rangle∣1⟩ を準備し、可変の遅延 τ\tauτ だけ待ってから測定します。∣1⟩|1\rangle∣1⟩ にとどまっている割合が減衰曲線を描きます。

ブロッホ球で見る​

T1T_1T1​ 緩和により励起状態は平衡状態に戻るため、ブロッホベクトルは zzz 軸に沿って ∣1⟩|1\rangle∣1⟩ から ∣0⟩|0\rangle∣0⟩ へと戻っていきます。

遅延スキャンの構築とトランスパイル​

遅延時間は具体的な値でなければならない(ハードウェア時間でスケジュールされる)ため、遅延ごとに1つの回路を構築します。

# Scale the T1 delay sweep to the qubit's reported coherence, and snap each delay to an integer
# number of samples (dt) so there are no "duration rounded" warnings (as in the Ramsey/echo cells).
T1_us = (backend.qubit_properties(QUBIT).t1 or 100e-6) * 1e6  # reported T1 (us)
delays_us = np.linspace(0, 5 * T1_us, 20)  # 0 .. ~5 T1 captures the full decay
print(f"T1 sweep: 0..{5*T1_us:.0f} us in {len(delays_us)} points")

dt = backend.dt
t1_circuits = []
for tau in delays_us:
    n_dt = int(round(tau * 1e-6 / dt))  # integer samples -> no rounding warning
    qc = QuantumCircuit(1, 1)
    qc.x(0)  # pi pulse: prepare |1>
    qc.delay(n_dt, 0, unit="dt")  # wait tau
    qc.measure(0, 0)
    t1_circuits.append(qc)

t1_isa = pm_q.run(t1_circuits)
T1 sweep: 0..1393 us in 20 points

実行​

t1_job = sampler.run([(c,) for c in t1_isa], shots=1000)
t1_res = t1_job.result()

実験: T2T_2T2​、T2∗T_2^*T2∗​​

理論​

T1T_1T1​ はエネルギーの損失を測ります。T2T_2T2​ は横平面における位相コヒーレンスの損失を測ります。これはラムゼー実験で観測できます。π/2\pi/2π/2 パルスがすべてのスピンを赤道面まで倒し、すべてが同じ向きを指します。スピンはラーモア歳差運動をしますが、それぞれがわずかに異なる周波数で歳差運動するため、赤道面上で扇状に広がり、正味の横方向の信号は特性減衰時間 T2∗T_2^*T2∗​ で減衰します。

量子分野の読者向けの補足: 扇状に広がる描像は、コヒーレンスを失う一つの方法、つまり平均化されて消える確定した位相の広がりを示しています。ただし、これが唯一の機構ではないことは知っておく価値があります。位相が環境とエンタングルしてしまい、系がそもそも確定した値を保持していない、という形でもコヒーレンスは失われます。信号の減衰を見ているだけでは2つの機構を区別できないため、扇状に広がる描像は直観的な理解として有用です。ただし、完全で文字通りの説明として受け取らないよう注意してください。

スピンの位相を乱す効果は2つあります。

  • 他の自由度との制御できない結合から生じる、不可逆(または事実上不可逆)なデコヒーレンス。真の T2T_2T2​ で特徴づけられます。NMRでは、これは一般にスピン間の結合を変調する分子運動に由来します。量子コンピューティングでは、量子ビットと環境との間の望ましくない結合に相当します。
  • 静的またはゆっくり変化する可逆な周波数オフセット。磁場の不均一性、量子ビット間の周波数のばらつき、較正誤差などです。真の T2T_2T2​ と組み合わさって、ラムゼー実験で観測されるより短い見かけの減衰時間 T2∗T_2^*T2∗​ を生じさせます。

では、ラムゼー実験で分かるのが T2∗T_2^*T2∗​ だけなら、真の T2T_2T2​ はどのように求めればよいのでしょうか。ハーン・エコーと呼ばれる2つ目の実験は、第2の種類のノイズをすべて打ち消して真の T2T_2T2​ を求めます。最初はラムゼー実験と同じく π/2\pi/2π/2 パルスで始まり、スピンが先ほどと同様に扇状に広がります。時間 τ\tauτ の後に π\piπ パルスを加えます。このパルスは静的な周波数オフセットによる位相の蓄積を反転させるため、同じ長さ τ\tauτ の2回目の遅延の後にスピンが再び収束します。

T2∗T_2^*T2∗​ と T2T_2T2​ は、化学の場面でも量子コンピューティングの場面でも、どちらも知っておくべき重要な数値です。化学の場面では、T2∗T_2^*T2∗​ が標準的なNMR実験の線幅を決めます(これが何を意味するかは、後のセクションで見ます)。T2T_2T2​ は分子のタンブリングなど分子について多くのことを教えてくれ、T2T_2T2​ の変化は、分子がより大きなものに結合したことを示す場合があります。量子コンピューティングの場面では、デコヒーレンスが系を圧倒する前により多くの時間を実験に使えるよう、一般に T2T_2T2​ と T2∗T_2^*T2∗​ の両方をできるだけ長くしたいと考えます。ハーン・エコーに基づく一群の技法は、可逆なノイズを打ち消すことでこの時間を延ばし、回路が理想的には T2∗T_2^*T2∗​ ではなく真の T2T_2T2​ で制限されるようにします。これは「動的デカップリング」と呼ばれます。

実装​

量子ビットでラムゼー実験とハーン・エコー実験を実装する場合、読み出しはNMRの場合とは少し異なります。NMRでは、横平面でラーモア周波数で歳差運動するスピンが誘起する振動磁場を直接観測できます。しかし量子ビットでは、ZZZ 軸への射影、つまり ∣0⟩\vert 0 \rangle∣0⟩ か ∣1⟩\vert 1 \rangle∣1⟩ かしか測定できません。そのため、どちらの実験でも、最後にもう1つの π/2\pi/2π/2 パルスを加えてから測定します。この π/2\pi/2π/2 パルスは、量子ビットの位相情報を占有率へと変換します。

以下で、T2∗T_2^*T2∗​ と T2T_2T2​ を求めるために各実験を実行します。

ラムゼー (T2∗T_2^{*}T2∗​): 遅延時間 τ\tauτ を挟む2つの π/2\pi/2π/2 パルス​

最初の π/2\pi/2π/2 パルスはブロッホベクトルを赤道面に倒し、次のパルスはブロッホベクトルの位相を占有率に変換します。ブロッホベクトルが歳差運動するにつれて位相は時間とともに変化するため、占有率は歳差時間 τ\tauτ の関数として正弦波状のパターンを示します。量子ビットが位相コヒーレンスを失うにつれて、この正弦曲線の振幅が減衰するのが見えるはずです。

量子分野の読者向けのもう少し細かい点: 量子コンピューティングの実験で見える振動は、実際にはラーモア周波数のものではありません。ラーモア周波数はGHz帯で、速すぎて分解できないからです。量子実験は回転座標系で行われます。これは量子ビットと(ほぼ)ラーモア周波数で一緒に回転する座標系で、速い歳差運動は見えなくなり、ブロッホベクトルはほぼ静止して見えます。干渉縞を見るために、回転座標系をラーモア周波数からわずかにずらして意図的に設定します。すると、ブロッホベクトルはその小さな離調で歳差運動しているように見え、離調周波数の振動信号が得られます。以下では、離調を1つの値に固定せず、(量子ビットのコヒーレンス時間に合わせて決めた)測定ウィンドウに約12本の干渉縞が収まるように選びます。これにより、エイリアシングなしで振動を容易にサンプリングできます。もう一つの複雑な点として、Qiskitでは、(回転座標系の周波数を決める)パルス周波数を変更するのに必要なパルスレベルの制御ができません。代わりに、2つ目のラムゼー・パルスの位相を設定することで、実効的な離調を手動で加えます。やや作為的ですが、結果は同じであり、観測される減衰は依然として本物の T2∗T_2^*T2∗​ です。

ブロッホ球で見る​

π/2\pi/2π/2 パルスがスピンを赤道面に倒します。その後、各スピンはわずかに異なる速度で歳差運動して扇状に広がるため、位相が乱れるにつれて正味の(赤い)ベクトルは縮みます。この減衰が T2∗T_2^*T2∗​ です。

# Adaptive Ramsey: scale the window to the reported coherence and choose the detuning so a fixed
# number of fringes span it. This decouples the point count from the window -- a long window stays
# cheap and cannot alias (we keep 8 samples per fringe).

f_detune = n_fringes / (
    ramsey_span * 1e-6
)  # adaptive detuning (Hz) -> low, so a long window is cheap
samp_per_fringe = 8
n_ramsey = n_fringes * samp_per_fringe + 1  # ~97 points, fixed regardless of T2

print(
    f"Ramsey sweep: 0..{ramsey_span:.0f} us in {n_ramsey} points "

# Initial guesses / bounds derived from the reported coherence so the fits track the scaled axes.
T2_us = (backend.qubit_properties(QUBIT).t2 or 100e-6) * 1e6

# Ramsey: decaying oscillation -> extract T2*
def ramsey_fn(t, A, T2s, f, phi, B):
    return A * np.exp(-t / T2s) * np.cos(2 * np.pi * f * t + phi) + B

rp0 = [0.4, T2_us / 2, f_detune * 1e-6, 0.0, 0.5]  # T2* guess ~ half the echo T2
rbounds = (
    [0, 0.1, 0, -np.pi, 0],
    [1, 2 * T2_us, 5, np.pi, 1],
)  # keep the fit from collapsing to ~0

理解度チェック​

通常は T2≳T2∗T_2 \gtrsim T_2^{*}T2​≳T2∗​ となるはずです。その理由を1文で説明し、ハーン・エコーの π\piπ パルスがどのような物理的効果を取り除くか、そして何を取り除けないかを述べてください。

解答

T2∗T_2^{*}T2∗​ は不可逆な位相緩和と可逆な静的広がりの両方を含むため、より速く減衰します。エコーの π\piπ パルスは静的で可逆な位相緩和(磁場の不均一性や固定周波数のオフセット)を再収束させ、不可逆なスピン-スピン位相緩和だけを残します。これが真の T2T_2T2​ です。エコーは、系列の前半と後半の間で変化するゆらぎを元に戻すことはできません。

分子のNMR分光: 化学シフトと JJJ カップリング​

1つのスピンから分子へ​

ここまでの実験では、単一の孤立したスピンを特徴づけてきました。実際の化学NMRでは分子(結合した多数のスピンを同時に)を読み取り、得られたスペクトルから分子構造の特徴を推測します。これにより、2つの効果が分かります。

  • 化学シフト。 化学的に異なる各核は、局所的な電子が印加磁場を異なる量だけ遮蔽するため、わずかに異なる周波数 νi\nu_iνi​ で歳差運動します。したがって、ピークの位置から化学環境が分かります(たとえば、CH3_33​ のプロトンと芳香族のプロトンの違いなど)。

  • スカラー JJJ カップリング。 2つのスピンの間の結合を介した相互作用により、各ピークが多重線に分裂します。nnn 個の等価な隣接核を持つ核は、二項分布の強度を持つ n+1n+1n+1 本の線に分裂します。これが n+1n+1n+1 則です。分裂のパターンは結合関係(どの核が結合しているか)を明らかにし、間隔が結合定数 JJJ です。

実験の手順​

これを量子コンピューターでモデル化するには、量子ビット上にスピンハミルトニアンを実装する必要があります。弱結合・高磁場の極限(化学シフトの差 ≫\gg≫ カップリング)では、カップリングの XXXXXX 部分と YYYYYY 部分は平均化されて消え、ZZZZZZ だけが残ります。したがってハミルトニアンは次のようになります(角周波数の単位、ℏ=1\hbar=1ℏ=1)。

H=∑iπ νi Zi⏟chemical shift  +  ∑i<jπ2 Jij ZiZj⏟J-coupling.H = \underbrace{\sum_i \pi\,\nu_i\, Z_i}_{\text{chemical shift}} \;+\; \underbrace{\sum_{i<j} \tfrac{\pi}{2}\,J_{ij}\, Z_iZ_j}_{J\text{-coupling}}.H=chemical shifti∑​πνi​Zi​​​+J-couplingi<j∑​2π​Jij​Zi​Zj​​​.

各核は1つの量子ビットです。化学シフトは単一量子ビットの ZZZ 回転であり、カップリングは2量子ビットの ZZZZZZ 相互作用です。

実験は次のように進みます。π/2\pi/2π/2 パルスがすべてのスピンを横平面に倒し、スピンは時間 ttt の間、歳差運動とカップリングを行います。すべてのスピンについて合計した複素横磁化 s(t)=⟨X⟩+i⟨Y⟩s(t) = \langle X\rangle + i\langle Y\rangles(t)=⟨X⟩+i⟨Y⟩ を記録します。上のラムゼー実験と同様に、この横磁化は歳差時間 ttt の関数として減衰する正弦波を描きます。この信号のフーリエ変換を取ると、化学シフト νi\nu_iνi​ にピークを持ち、スカラーカップリング JijJ_{ij}Jij​ で分裂したスペクトルが得られます。

備考

分子の時間発展は、時間 ttt を回転角に対応させることでシミュレーションします。ttt が大きいほど ZZZ 回転と ZZZZZZ 回転が大きくなるのであって、回路が長くなったり深くなったりするわけではありません。したがって、シミュレーションされる状態は ttt とともに進みますが(これが自由誘導減衰(FID)を振動させる理由です)、物理的な量子ビットがそれ以上長く待機することはなく、ttt に依存するデコヒーレンスもありません。そのため、シミュレーションされたFIDはそれ自体では減衰しません。無限に長い理想的なFIDであればスペクトル線は無限に鋭くなりますが、有限のサンプリングウィンドウでは有限の分解能になり、スペクトル漏れが生じることがあります。実際のNMRの線は、T2∗T_2^*T2∗​ で決まる有限の幅を持ちます。これを補うために、フーリエ変換の前にFIDへウィンドウ e−t/T2∗e^{-t/T_2^{*}}e−t/T2∗​ を掛けます。これは線幅拡大アポダイゼーションと呼ばれ、分光学者が線幅を設定するために処理で適用します(分解能と信号対雑音比のトレードオフになります)。(このモジュールの付録にあるオプションのセルでは、トロッター化した代替手法を示します。そこでは、回路の深さとともに増大する実際のデコヒーレンスによって減衰が生じます。)

AX系​

マッピングと最適化​

化学シフトのオフセット νi\nu_iνi​ とカップリング JijJ_{ij}Jij​ が与えられたとき、パラメーター化された状態準備回路を返す関数を1つ書きます。π/2\pi/2π/2 パルスがスピンを赤道面に倒し、その後 ZZZ 回転が、化学シフト項と JJJ カップリング項のもとでの状態の時間発展をシミュレーションします。各 νi\nu_iνi​ は、選んだ基準(回転座標系のキャリア)に対する、Hz単位の小さな歳差オフセットです。ここでは手動で設定しますが、実際の分子では、電子による遮蔽が局所磁場を変え、基準に対する各核の共鳴をずらします。これは、スピンごとに1つずつの単一量子ビット RZR_ZRZ​ ゲートでモデル化され、各 νi\nu_iνi​ がそのスピンのピークがスペクトル上のどこに位置するかを決めます。2量子ビットの ZZZZZZ ゲートはカップリング JijJ_{ij}Jij​ を加え、各ピークを多重線に分裂させ、線の間隔を決めます。

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit.quantum_info import SparsePauliOp

t = Parameter(
    "t"
)  # evolution time (arbitrary units; the frequencies below are in matching units)

def fid_circuit(offsets, couplings):
    """State-preparation circuit for a set of spins: a pi/2 pulse, then evolution under the
    chemical-shift + J-coupling Hamiltonian for time t. No measurement -- the Estimator reads
    <X> and <Y> directly.

    offsets   : list of chemical-shift frequencies nu_i, one per qubit
    couplings : dict {(i, j): J_ij}
    """
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # pi/2 pulse: tip every spin into the transverse plane
    for i, nu in enumerate(offsets):
        qc.rz(2 * np.pi * nu * t, i)  # chemical-shift precession -> line at nu_i
    for (i, j), J in couplings.items():
        qc.rzz(np.pi * J * t, i, j)  # J-coupling -> splitting of size J
    return qc

def transverse_obs(n):
    """Total transverse observables (sum over spins): (sum_i X_i, sum_i Y_i)."""
    ox = SparsePauliOp.from_sparse_list(
        [("X", [i], 1.0) for i in range(n)], num_qubits=n
    )
    oy = SparsePauliOp.from_sparse_list(
        [("Y", [i], 1.0) for i in range(n)], num_qubits=n
    )
    return ox, oy

def run_fid(isa_circ, n, est):
    """Complex FID s(t) = sum_i <X_i> + i <Y_i> over the time grid, via the Estimator."""
    ox, oy = transverse_obs(n)

理解度チェック​

各問題を読み、答えを考えてから、三角形をクリックして解答を表示してください。

AXスペクトルでは、2つの二重線が(中心間で)12 Hz離れており、各二重線内の2本の線は2 Hz離れています。化学シフトの差はどちらの数値で、カップリング定数 JJJ はどちらでしょうか。磁場が2倍の分光計に移った場合、どちらが変化するでしょうか。

解答

12 Hzの中心間の間隔が化学シフトの差(ν1−ν2\nu_1-\nu_2ν1​−ν2​)で、2 Hzの線の間隔がカップリング定数 JJJ です。化学シフトは B0B_0B0​ の遮蔽に由来するため、磁場に比例してスケールします。磁場が2倍になると間隔は24 Hzに倍増します。カップリング JJJ は結合を介した分子の性質であり、磁場に依存しないため、2 Hzのままです。化学者は、分裂が磁場に対してどうスケールするかを見ることで、シフトとカップリングを見分けます。

n+1n+1n+1 則を用いて、3つ目の等価なXスピンが加わった場合(AX3_33​ 系)のAの多重線を予測し、AX2_22​ にある2つの等価なXスピンが互いを分裂させない理由を説明してください。

解答

n=3n=3n=3 個の等価な隣接核があるため、Aは1:3:3:1の四重線になります。等価なスピン同士が互いを分裂させないのは、それらのカップリングが関連するエネルギー準位をすべて同じ量だけずらすため、それらの準位の間隔(私たちが観測する周波数)が変化しないからです。

付録(オプション): トロッター化された時間発展 — デコヒーレンスに線幅を決めさせる​

分子のNMR分光のセクションでは、時間発展 e−iHte^{-iHt}e−iHt は ttt とともに深さが増えない単一の層として適用されるため、FIDはそれ自体では減衰せず、線幅は e−t/T2e^{-t/T_2}e−t/T2​ のアポダイゼーション・ウィンドウで与えました。このオプションのセルでは、逆のアプローチを取ります。時間発展を ppp 個のトロッター・ステップに分割し、各ステップの後にバリアを置きます(トランスパイラーがそれらを1つの層にまとめ直せないようにするためです)。時間点 kkk は kkk ステップを使うため、回路の深さは時間とともに増えます。

HHH のすべての項は可換なので、これは厳密です。ノイズのないシミュレーターでは、同じ鋭いピークが得られます。しかし、ノイズモデルのバックエンドや実機では、蓄積するゲート誤差によってFIDがひとりでに減衰し、その減衰が線幅を決めます。これは、T2T_2T2​、T2∗T_2^*T2∗​ 実験のセクションにある T2↔T_2\leftrightarrowT2​↔線幅という考え方であり、今回は処理ウィンドウではなく実際のデコヒーレンスから生じています。この方法で、AX系(2つの二重線)と**AX2_22​**系(1:2:1の三重線と二重線)の両方を実行します。

実用上の注意点が2つあります。第一に、コストは深さです。最も深いAX回路は約 ∼ ⁣47\sim\!47∼47 個の2量子ビットゲートを使い、AX2_22​ 版はその約2倍になるため、どちらも厳密版よりはるかにノイズが多く、コストも高くなります。第二に、各スピン系は引き続き1つのジョブとして送信され、すべての時間点は分光のセクションで選んだものと同じ物理量子ビットのレイアウトを再利用します。USE_BATCH=True の場合、これらのジョブはノートブック全体で共有するオプションのバッチも使用します。

# Trotterized FID: depth grows with time, so real decoherence (not apodization) sets the linewidth.
estimator.options.default_shots = 2000  # deep circuits need more shots in this appendix
n_tr, dt_tr = (
    48,
    1 / 20,
)  # Nyquist = 1/(2 dt) = 10 Hz (covers the AX2 triplet's 8 Hz line)
times_tr = np.arange(n_tr) * dt_tr
APODIZE_TROTTER = False  # keep False so the linewidth comes from decoherence

def trotter_fid_circuit(offsets, couplings, p, step):
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # 90-degree pulse
    for _ in range(p):  # p Trotter steps, each of duration `step`
        for i, nu in enumerate(offsets):
            qc.rz(2 * np.pi * nu * step, i)  # chemical-shift evolution for one step
        for (i, j), J in couplings.items():
            qc.rzz(np.pi * J * step, i, j)  # J-coupling evolution for one step
        qc.barrier()  # <-- stops the transpiler merging the steps
    return qc

def run_trotter(offsets, couplings, n, est, pass_manager):
    # Time point k uses k Trotter steps (its own circuit). Submit every time point and both
    # quadratures together as ONE Estimator job, using one fixed physical-qubit layout.
    ox, oy = transverse_obs(n)
    pubs = []
    for k in range(n_tr):
        isa = pass_manager.run(trotter_fid_circuit(offsets, couplings, k, dt_tr))
        pubs.append((isa, ox.apply_layout(isa.layout)))  # <X> at time k
        pubs.append((isa, oy.apply_layout(isa.layout)))  # <Y> at time k
    res = est.run(pubs).result()
    return np.array(
        [res[2 * k].data.evs + 1j * res[2 * k + 1].data.evs for k in range(n_tr)]
    )

def trotter_spectrum(fid):
    sig = fid * np.exp(-times_tr / 1.0) if APODIZE_TROTTER else fid
    spec = np.abs(np.fft.fftshift(np.fft.fft(sig)))
    freq = np.fft.fftshift(np.fft.fftfreq(n_tr, dt_tr))
    return freq, spec

fid_tr = run_trotter(
    ax_offsets, ax_couplings, 2, estimator, pm_ax
)  # AX  -> two doublets
fid2_tr = run_trotter(
    ax2_offsets, ax2_couplings, 3, estimator, pm_ax2
)  # AX2 -> triplet + doublet

f_ax, s_ax = trotter_spectrum(fid_tr)
f_ax2, s_ax2 = trotter_spectrum(fid2_tr)

fig, ax = plt.subplots(1, 3, figsize=(15, 4))
ax[0].plot(times_tr, np.abs(fid_tr), "o-", label="AX")
ax[0].plot(times_tr, np.abs(fid2_tr), "s-", label="AX$_2$")
ax[0].set_xlabel("evolution time $t$")
ax[0].set_ylabel("|FID|")
ax[0].set_title("Trotter FID envelope (decays only on a noisy backend)")
ax[0].legend()
ax[1].plot(f_ax, s_ax)
ax[1].set_xlim(-12, 12)
ax[1].set_xlabel(r"frequency $\nu$ (Hz)")
ax[1].set_ylabel("intensity")
ax[1].set_title("AX: two doublets")
ax[2].plot(f_ax2, s_ax2)
ax[2].set_xlim(-12, 12)
ax[2].set_xlabel(r"frequency $\nu$ (Hz)")
ax[2].set_title("AX$_2$: 1:2:1 triplet + doublet")
plt.tight_layout()
plt.show()
print(
    f"Deepest AX circuit: {n_tr-1} two-qubit gates;  deepest AX2 circuit: {2*(n_tr-1)} two-qubit gates."
)
print(
    "Noiseless backend: |FID| stays flat, peaks razor-sharp (set APODIZE_TROTTER=True to tame ripples)."
)
print(
    "Noise-model backend / hardware: |FID| decays on its own and the peaks gain a real linewidth."
)
