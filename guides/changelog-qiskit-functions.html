Qiskit Functions

2026年7月​

  • Qiskit Functions v0.17.0における新しい事前チェックと新しいbackendメソッド: qiskit-ibm-catalogの新しいメソッドにより、実行前にランタイム容量とバックエンドへのアクセスを確認できるようになり、run()はジョブを送信する前にその両方を検証するようになりました。

    • 新機能

      • 関数に対してrun()を呼び出すと、サービスはまず3つのことを確認します。インスタンスにランタイム容量があるか、指定したバックエンドにアクセスできるか、そして少なくとも1つのバックエンドが利用可能かどうかです。何か問題がある場合、キューで待つことなく、その場で明確なエラーが表示されます。

        これらのリソースは、いつでも自分で確認することもできます。

        • usage()で残りのランタイム容量を確認します。

        • backends()でインスタンスがアクセスできるバックエンドの一覧を確認します。

        • backend()で単一のバックエンドを調べ、アクセス権限を確認します。

        • least_busy()で保留中のジョブが最も少ないバックエンドを見つけます。

    • 一般的な利用例

      • 長時間のジョブバッチを実行する前に残りの容量を確認し、完了に十分な容量がない場合は実行をスキップします。

      • バックエンド名をハードコーディングする代わりに、コード内でバックエンドを選択します。

      • キューで待つのではなく、パイプラインやノートブックで早期に失敗を検出します。

    • はじめに

      • まず、qiskit-ibm-catalogの最新バージョンを実行していることを確認してください。

        pip install --upgrade qiskit-ibm-catalog

      • 詳細と例については、ドキュメントを参照してください。

2025​

Third quarter

2025年7月18日​

Qiskit Functionsのテンプレートは、独自のカスタム実験のために新しいツール、メソッド、または構成に置き換えられるモジュール式のパイプラインを提供します。すべての関数テンプレートはQiskit Serverlessにも簡単にデプロイでき、ワークフロー実行の一部として古典コンピューティングを容易に活用できます。サーバーレスパッケージは、任意のクラウド環境にデプロイすることも、PremiumおよびFlex Planユーザー向けにIBMが提供するホスト型サービスを利用することもできます。どちらのオプションを選んでも、Qiskit Serverlessは実行を簡素化し、ワークフローの一部を並列化するのに役立ちます。

詳細についてはQiskit Functionsテンプレートガイドを参照するか、ドキュメントのQiskit Functionsの概要をお読みください。

Second quarter

2025年6月5日​

  • 金融と最適化のための2つの新しい関数を提供開始することを嬉しく思います。

    • ColibriTDによるQUICK-PDEは、材料変形や計算流体力学の問題に対する特定の微分方程式を解くことができます。例えば、ある研究チームは既にQUICK-PDE関数を使用して、Small Modular Reactorsと呼ばれるタイプの原子炉でより効率的に熱を伝達するために開発された新しい反応性流体のダイナミクスを研究し始めています。

    • Global Data QuantumによるQuantum Portfolio Optimizerは、定量金融の研究者がポートフォリオ最適化戦略をバックテストできるようにします。100量子ビットを超える規模で実行されるこの関数は、指定された期間にわたってポートフォリオのシャープレシオとリターンを計算します。初期のユーザーは、投資戦略の過去のパフォーマンスを評価する能力や、類似条件下での異なるポートフォリオの比較を可能にするこのオプティマイザーの機能を検証しています。

無料トライアルをお申し込みいただくには、Qiskit Functionsカタログをご覧ください。

2025年5月16日​

  • 今後数週間にわたり、すべての関数がワークフローの実行、デバッグ、分析を支援する詳細情報を提供するようになります。これには以下が含まれます。

    • ジョブが失敗した場合、job.error_message()を使用して、ワークフローのデバッグに役立つ具体的なエラーコードとメッセージを見つけることができます

    • job.status()は、FunctionがRUNNING中に何が起きているかについて、以下を含む詳細情報を提供します。

      • RUNNING: MAPPING

      • RUNNING: OPTIMIZING_FOR_HARDWARE

      • RUNNING: WAITING_FOR_QPU

      • RUNNING: EXECUTING_QPU

      • RUNNING: POST_PROCESSING

    • 最後に、Qiskit Functionが完了した後、次の例のようにjob.result()['metadata']['resource_usage']で各ステージにかかった時間を調べることができます。

Expand for code example
{
      ...,
  "metadata": {
    "resource_usage": {
      {
        "RUNNING: MAPPING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: OPTIMIZING_FOR_HARDWARE": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: WAITING_FOR_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: EXECUTING_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: POST_PROCESSING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
      },
    }
  }
}

これらの変更により、Qiskit Functionsがより使いやすくなることを期待しています。今すぐカタログで無料トライアルを始めることができます。

2024​

2024年9月16日​

  • IBM Quantum Premium Planユーザー向けにQiskit Functionsプレビューを導入しました。始めるには、pip install qiskit-ibm-catalogを実行し、Qiskit Functionsドキュメントをご覧ください。Qiskit Functions Catalogクライアントを使用すると、研究を加速するために設計された抽象化されたサービスにワークロードを送信できます。既存のIBM Quantum Platformの認証情報でサインインしてください。

    Qiskit Functions Catalogプレビューでは、Premium Planユーザーが、IBMによって作成された関数やエコシステムの他のメンバーによって作成された関数を含む、利用可能な関数を探索できます。カタログにはCircuit functionsとApplication functionsの2種類の関数が含まれています。

    • Circuit functionsは、回路を実行するための簡素化されたインターフェースを提供します。ユーザーが提供する抽象回路とオブザーバブルを入力として受け取り、代表的なISA回路の合成、最適化、実行を管理します。Circuit functionsは、トランスパイル、エラー抑制、エラー緩和における最新の機能を統合し、すぐに使える実用レベルのパフォーマンスを実現します。これにより、計算科学者は問題ごとにパターンをゼロから構築するのではなく、問題を回路にマッピングすることに集中できます。

    • Application functionsは、アルゴリズムの探索やドメイン固有のユースケースなど、より高レベルのタスクをカバーします。エンタープライズの開発者やデータサイエンティストは、回路を扱うための量子情報科学の背景知識を持っていないことがありますが、その代わりに自分のドメイン知識を活かして量子コンピューティングのアルゴリズムやアプリケーションを進化させたいと考えています。Application functionsを使用すると、ユーザーは古典的な入力を入力するだけで解を受け取ることができ、ドメイン固有のワークフローに量子をより簡単に組み込んで実験できます。

  • Qiskit Functions Catalogの開始により、Premium Planの開発者はIBM Circuit functionを利用できるようになります。IBM Circuit functionには、回路の合成、最適化、スケジューリングのためのQiskitの最新のAI駆動型拡張機能に加え、今日のハードウェアで可能な限り正確な推定値を返すための高度なエラー緩和手法が含まれています。

    ユーザーは、パートナーであるQ-CTRL、QEDMA、Algorithmiqが提供する以下の関数のライセンスを購入できます。

  • Circuit functions

    • Q-CTRLは、AI駆動の量子制御技術を適用するcircuit functionをリリースします。これにより、ユーザーはより大きな問題にうまくスケールできます。

    • Algorithmiqは、PEC(確率的誤り相殺)手法よりも少ないショット数で推定値を得るための誤り緩和手法であるTEM(テンソルネットワーク誤り緩和)を適用するcircuit functionをリリースします。

    • QEDMAは、独自のプロトコルを使用してノイズのあるQPU操作を効率的かつ正確に特性評価し、その特性評価データに基づいてエラー抑制とエラー緩和を適用するcircuit functionをリリースします。

  • Application functions

    • Q-CTRLは、ユーザーがグラフや目的関数を渡すことで解のコストを受け取ることができる最適化ソルバーをリリースします。
