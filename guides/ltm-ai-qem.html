LTM による AI-QEM

備考

IBM Quantum® Functions はベータ機能で、IBM Quantum Premium Plan、Flex Plan、On-Prem（IBM Quantum Platform API 経由）Plan のユーザーのみが利用できます。ベータ機能は変更されることがあります。

API リファレンスを参照してください。

現在の制限事項

AI-QEM の現在のリリースには、次の制限事項があります。

  • エラー抑制は Heron プロセッサーファミリーに限定されています。 LTM は、今後のバージョンで追加のバックエンドをサポートする予定です。

  • エラー抑制は選択的に適用されます。 エラー抑制は、期待値の絶対値が ∣⟨O⟩noisy∣≥0.1|\langle O \rangle_{noisy}| \geq 0.1∣⟨O⟩noisy​∣≥0.1 を満たす場合にのみ実行されます。これにより、意味のある効果が見込まれる場合にのみエラー抑制が適用されます。

これらの制限事項は AI-QEM の現在の対象範囲を反映したものです。LTM が追加のワークフロー、バックエンド、機能のサポートを加えるにつれて、今後のリリースで緩和される可能性があります。

概要​

量子エラー抑制（QEM）には、ゼロノイズ外挿（ZNE）[2] や確率的エラーキャンセル（PEC）[3] などのアルゴリズム的プロトコルが含まれます。これらは、完全なフォールトトレランスに必要な大規模な量子ビットのオーバーヘッドを伴わずに、ノイズあり中規模量子（NISQ）ハードウェア上の期待値に生じるノイズ起因のバイアスを抑えるよう設計されています。これらの手法は、現在のプロセッサーから信頼できる物理シミュレーションやベンチマーク結果を得るうえで重要です。近年、多くの QEM 手法が開発されてきましたが、ほぼすべてが根本的なトレードオフを共有しています。精度を得るために QPU 時間を大幅に多く必要とするという点です。その決定的な制限は指数関数的なサンプリングオーバーヘッドです。ノイズのある回路からバイアスのない信号を再構成すると、推定量の統計的分散が大きく増加するためです。その結果、より高いノイズレベルを克服するには桁違いに多くの測定ショットが必要になり、QPU の実行時間が大幅に長くなり、ハードウェア上で深刻なボトルネックが生じます [4, 5, 6]。

AI-QEM を使用すると、ノイズのある QPU 上で量子回路を実行し、QPU の追加実行時間のオーバーヘッドなしに、他の AI ベースのエラー抑制手法よりも改善された期待値を得ることができます。このアプローチでは、グラフ畳み込みネットワーク（GCN）と Transformer を組み合わせたアーキテクチャのディープニューラルネットワークを使用します。このネットワークは、回路構造、バックエンドのトポロジー、パウリ観測量、量子ビットのキャリブレーションなどの特徴量で学習され、ζ\zetaζ で表される補正係数を予測します。ノイズありの期待値を ζ\zetaζ で割ることで、改善された期待値が得られます。実験では、AI-QEM が他の AI ベースの抑制手法よりも良い結果を出すことが示されています。特に、深さ（ゲート層）と幅（量子ビット数）が大きい回路で顕著であり、ユーティリティスケールの量子実験に適しています。ベンチマークセクションの表は、GCN-Transformer ベースのモデルが、80〜150 量子ビットの範囲でランダムフォレスト（RF）ベースのモデルを上回り、平均絶対誤差（MAE）が 0.343 であることを示しています。MAE とは、多数の回路と観測量の構成にわたる、理想的な期待値と、モデルがノイズのあるハードウェア結果を抑制した後の期待値との絶対差の平均です。さらに、このモデルは回路に依存しないため、回路固有のカスタマイズなしに、幅広い量子回路やアプリケーションに適用できます。

基盤となるコンポーネントの詳細な説明とユーティリティスケールのデモンストレーションについては、AI-QEM の論文 [1] を参照してください。

説明​

LTM AI-QEM function を使用して、特定の量子回路に対する観測量の期待値を推定します。LTM AI-QEM を使用するには、量子回路、測定する観測量のセット、QPU を指定します。この function は IBM Quantum Estimator プリミティブと同じ QPU 時間を使用し、追加の QPU 時間は必要ありません。

観測量 OOO の期待値を計算する通常の方法は、観測量をパウリ演算子の和 O=∑iciPiO=\sum_i{c_i}{P_i}O=∑i​ci​Pi​ に分解し、各パウリ演算子の期待値 ⟨Pi⟩\langle P_i \rangle⟨Pi​⟩ を個別に計算することです。観測量の期待値 ⟨O⟩\langle O \rangle⟨O⟩ は、パウリ期待値の同じ線形結合になります: ⟨O⟩=∑ici⟨Pi⟩{\langle O \rangle}=\sum_i{c_i}{\langle P_i \rangle}⟨O⟩=∑i​ci​⟨Pi​⟩。パウリ演算子の集合が互いに可換である場合、それらの期待値の計算に必要な測定を同時に行うことができます。LTM AI-QEM function で回路を実行すると、この function は Estimator プリミティブを使用して、通常どおりハードウェア上で回路を実行します。観測量をパウリ演算子に分解し、それらの期待値を個別に計算する手順も同じです。その後、ディープラーニングアーキテクチャである GCN-Transformer が、各パウリ演算子 PiP_iPi​ に対する補正係数 ζi\zeta_iζi​ を予測します。この function は、この補正係数を使用して各パウリ演算子のノイズありの期待値を補正します: ⟨Pi⟩mitigated=⟨Pi⟩noisyζi{\langle P_i \rangle}_{mitigated} = \frac{{\langle P_i \rangle}_{noisy}}{\zeta_i}⟨Pi​⟩mitigated​=ζi​⟨Pi​⟩noisy​​。したがって、抑制後の期待値は ⟨O⟩mitigated=∑ici⟨Pi⟩mitigated=∑ici⟨Pi⟩noisyζi{\langle O \rangle}_{mitigated} = \sum_i{c_i}{\langle {P_i} \rangle}_{mitigated} = \sum_i{c_i}{\frac{{\langle P_i \rangle}_{noisy}}{\zeta_i}}⟨O⟩mitigated​=∑i​ci​⟨Pi​⟩mitigated​=∑i​ci​ζi​⟨Pi​⟩noisy​​ となります。

LTM AI-QEM function を使用するワークフローは次のとおりです。

  1. 回路と観測量を定義します。

  2. 回路と観測量のペアをプリミティブ統合ブロック（PUB）として渡し、LTM AI-QEM function を実行します。

  3. 結果を取得します。結果には、各 PUB の対応する量子回路に対する観測量の期待値が含まれます。

多くのテスト例から、LTM AI-QEM function が観測量の推定を改善することが経験的に示されています。この function には次の特長があります。

  • ユーティリティスケールの実験: テスト例では、深さと幅の大きい回路において、AI-QEM が他の AI ベースの手法よりも優れた性能を示しています。結果についてはベンチマークセクションを参照してください。

  • プリミティブ: この function は Estimator プリミティブをサポートしているため、任意の量子回路に対する任意の観測量の期待値を計算できます。

  • プリミティブ統合ブロック（PUB）: LTM AI-QEM function は、Estimator プリミティブがサポートするすべてのタイプの PUB（つまり、すべての回路と観測量の構成）をサポートします。

AI-QEM 手法は、データセットの構築から始まります。ここでは、さまざまなパラメーター設定でランダムな量子回路が生成されます。各回路について、理想的な期待値（シミュレーションで取得）とノイズありの期待値（ハードウェアでの実行で取得）の両方が計算されます。これらの結果は、対応する量子回路とバックエンド情報とともに、データセットリポジトリに保存されます。その後、このデータセットを使用して、量子計算のノイズを抑制できる機械学習またはディープラーニングのモデルを学習し、学習済みモデルは将来の使用のために保存されます。推論時には、学習済みモデルは、量子回路、ハードウェアで計算されたそのノイズありの期待値、関連する観測量、バックエンド情報を入力として受け取ります。モデルはこれらの入力を処理して、ノイズを抑制した期待値を出力します。

例​

例 1: GHZ 回路​

この例では、単純な nnn 量子ビットの GHZ 回路と、GHZ 状態に対する期待値が 1 であることが分かっている 2 体テンソル積観測量 ZiZjZ_iZ_jZi​Zj​ を使用して、LTM AI-QEM function の基本的なワークフローを示します。

PUB を構築する​

Estimator プリミティブと同様に、LTM AI-QEM function はプリミティブ統合ブロック（PUB）を入力として受け付けます。PUB は (circuit, observables, parameter_values, precision) の形式のタプルで、parameter_values はパラメトリック回路では必須、precision は省略可能です。

回路​

nnn 量子ビットのグリーンバーガー・ホーン・ツァイリンガー（GHZ）状態は、次のように表されます。

∣GHZ⟩n=∣0⟩⊗n+∣1⟩⊗n2=∣00…0⟩⏞n 量子ビット+∣11…1⟩⏞n 量子ビット2.|GHZ\rangle_{n} = \frac{\vert{0}\rangle^{\otimes{n}} + \vert{1}\rangle^{\otimes{n}}}{\sqrt2} = \frac{\overbrace{\vert{00}\dots{0}\rangle}^{\text{$n$ 量子ビット}} + \overbrace{\vert{11}\dots{1}\rangle}^{\text{$n$ 量子ビット}}}{\sqrt2}.∣GHZ⟩n​=2​∣0⟩⊗n+∣1⟩⊗n​=2​∣00…0⟩​n 量子ビット​+∣11…1⟩​n 量子ビット​​.

nnn 量子ビットの GHZ 状態を構築するには、すべての量子ビットを ∣0⟩|0\rangle∣0⟩ 状態に初期化し、最初の量子ビットにアダマールゲートを適用して等しい重ね合わせを作ります。次に、量子ビット iii を制御、量子ビット i+1i+1i+1 をターゲットとして、レジスタ全体に CNOT ゲートの列を適用します。この階段状のもつれ生成ゲートの列によって、最初の重ね合わせがすべての量子ビットに伝播し、もつれた GHZ 状態が得られます。

観測量​

GHZ 状態に対して 2 体テンソル積 Zi⊗ZjZ_i \otimes Z_jZi​⊗Zj​ を測定すると、レジスタ内の任意の 2 つの量子ビット間のパリティ相関が評価されます。GHZ 状態はすべて 0 の状態とすべて 1 の状態の重ね合わせであるため、任意の 2 つの量子ビットは完全に相関します。固有値は、∣00…0⟩\vert00\dots0\rangle∣00…0⟩ の分岐では (+1×+1)=1(+1 \times +1) = 1(+1×+1)=1、∣11…1⟩\vert11\dots1\rangle∣11…1⟩ の分岐では (−1×−1)=1(-1 \times -1) = 1(−1×−1)=1 です。どちらの分岐も +1 を返すため、理論上の期待値は 1 です。SparsePauliOp クラスで観測量を構築します。

この回路はパラメトリックではないため、PUB を (circuit, observable) として構築します。

from qiskit import QuantumCircuit
from qiskit.quantum_info import SparsePauliOp

def construct_ghz_circuit(n: int):
    """Constructs GHZ circuit with n qubits."""
    circuit = QuantumCircuit(n)
    circuit.h(0)
    for i in range(n - 1):
        circuit.cx(i, i + 1)
    return circuit

# Construct a GHZ circuit with the specified number of qubits
num_qubits = 50
ghz_circuit = construct_ghz_circuit(num_qubits)

# Observables
obs = SparsePauliOp.from_sparse_list(
    [("ZZ", [0, 49], 1.0)], num_qubits=num_qubits
)

# PUB
pub = (ghz_circuit, obs)

print("Details:")
print(f"\tNumber of Qubits: {num_qubits}")
print(f"\tCircuit Depth: {ghz_circuit.depth()}")
print(f"\tObservable: {obs}")

ghz_circuit.draw("mpl", fold=-1, scale=0.5)

例 2: ミラー回路​

この例では、ミラー回路を使用して、さまざまな形状の PUB で渡された観測量の期待値を計算します。LTM AI-QEM function と、さまざまな PUB の形状との互換性を示し、抑制後の結果と抑制なしの結果を比較します。

ミラー回路は、ランダムに生成された回路を適用し、その後にその逆回路を適用します。理想的でノイズのない実行では、2 つの半分が打ち消し合い、量子ビットは初期状態に戻ります。このため、本来は予測可能な結果に対して、ハードウェアとランタイムのノイズがどのような影響を与えるかを調べるのにこの回路が役立ちます。

この例では、複数の PUB を構築します。各 PUB は、同じミラー回路と、異なる形状で与えられたパウリ演算子からなる観測量を組み合わせたものです。

LTM AI-QEM function はこれらの観測量を評価し、ノイズのある実行から得られた期待値と、抑制後の値の両方を返します。この例には 2 つの目的があります。1 つは、この function がサポートされている PUB 形式を受け付けることを確認すること、もう 1 つは、抑制後の期待値とノイズありの値を比較して、エラー抑制ワークフローがミラー回路の期待される動作をどの程度効果的に回復するかを確認することです。

PUB を構築する​

各 PUB は、回路と観測量のリストのタプルです。この function は、回路に対する観測量の期待値を計算します。この例では、すべての観測量の構成で回路は同じです。PUB のリスト pubs を ltm_function に渡して実行します。

回路​

まず、5 量子ビットのミラー回路を作成します。そのために、Qiskit の random_circuit 関数でランダム回路を作成します。量子ビット数（n_qubits=5）、回路の深さ（depth=5）、再現性のためのシード（seed=42）を指定します。次に、ランダム回路の末尾に barrier を追加し、unitary_overlap を使用してミラー回路を作成します。unitary_overlap(U1, U2) は U2†U1U_{2}^{\dagger}U_{1}U2†​U1​ に対応する回路を作成するため、同じ回路を両方の引数として渡すとミラー回路が作成されます。barrier は、トランスパイル中に回路が恒等回路になるのを防ぎます。コードの出力にはミラー回路の深さが表示されます。depth=5 の場合、バリア層を加えて約 10 になると想定されます。

観測量​

次に、期待値を計算したい観測量のリストを、さまざまな形式で作成します。まず、変数 ALL_X_PAULI = XXXXX、ALL_Y_PAULI = YYYYY、ALL_Z_PAULI = ZZZZZ を定義します。これらは、5 つのすべての量子ビットに対する対応するパウリ観測量を表します。

次に、3 つの観測量のリストとして obs_1 を定義します。1 つ目は、2 つのパウリ演算子の線形結合 0.3 ZZZZZ+0.5 XXXXX0.3\,ZZZZZ + 0.5\,XXXXX0.3ZZZZZ+0.5XXXXX で、SparsePauliOp として定義します。2 つ目は SparsePauliOp([ALL_Z_PAULI]) で、これも SparsePauliOp です。3 つ目はパウリ文字列 ALL_X_PAULI です。obs_1 を持つ PUB の観測量配列の形状は (3,) です。

最後に、行列レイアウト、つまりリストのリストとして obs_2 を定義します。各内側のリストには、SparsePauliOp 型の観測量またはパウリ文字列が含まれます。1 行目には ALL_X_PAULI と 0.3 ZZZZZ+0.5 YYYYY0.3\,ZZZZZ + 0.5\,YYYYY0.3ZZZZZ+0.5YYYYY が含まれます。2 行目には 0.3 XXXXX+0.5 ZZZZZ0.3\,XXXXX + 0.5\,ZZZZZ0.3XXXXX+0.5ZZZZZ と 2.0 ZZZZZ2.0\,ZZZZZ2.0ZZZZZ が含まれます。obs_2 を持つ PUB の観測量配列の形状は (2, 2) です。

2 つの PUB を pubs = [(mirror_circuit, obs_1), (mirror_circuit, obs_2)] としてまとめます。

import numpy as np
from qiskit.circuit.library import unitary_overlap
from qiskit.circuit.random import random_circuit
from qiskit.quantum_info import SparsePauliOp

def create_mirror_circuit(
    n_qubits: int, depth: int, seed: int = 42
) -> QuantumCircuit:
    """Generates an n-qubit random circuit followed by its inverse (mirror) and measure all qubits."""  # noqa: E501
    circuit = random_circuit(n_qubits, depth=depth, seed=seed)
    circuit.barrier()
    mirror_circuit = unitary_overlap(circuit, circuit)
    return mirror_circuit

例 4: ブリックワーク型クリフォード回路​

この例では、クリフォード回路をシミュレーションします。この回路ファミリーは、既知の期待値を持つようにシミュレーションを設計できるため便利です。具体的には、次のようにして、期待値が常に 1 になるように回路と観測量を設計できます。

  1. 出発点（スタビライザー）: 真空状態 ∣0⟩⊗n|0\rangle^{{\otimes}n}∣0⟩⊗n から始めます。∣0⟩|0\rangle∣0⟩ にパウリ ZZZ または恒等演算子を適用しても状態は変わりません: Z∣0⟩=∣0⟩Z|0\rangle = |0\rangleZ∣0⟩=∣0⟩ および I∣0⟩=∣0⟩I |0\rangle = |0\rangleI∣0⟩=∣0⟩。したがって、ZZZ と III のみのテンソル積であるパウリ文字列 PPP は、すべて 0 の状態 ∣0⟩⊗n|0\rangle^{{\otimes}n}∣0⟩⊗n を変化させません: P∣0⟩⊗n=∣0⟩⊗nP |0\rangle^{{\otimes}n} = |0\rangle^{{\otimes}n}P∣0⟩⊗n=∣0⟩⊗n。

  2. クリフォードの時間発展: ユニタリ ULU_LUL​ を状態に適用すると、∣ψ⟩=UL∣0⟩⊗n|\psi\rangle = U_L |0\rangle^{{\otimes}n}∣ψ⟩=UL​∣0⟩⊗n になります。この新しい状態に対する期待値が 1 になる観測量を求めるには、同じユニタリ変換を演算子に適用します: OL=ULPUL†O_L = U_L P U_L^{\dagger}OL​=UL​PUL†​。これは量子力学のハイゼンベルク描像です。

  3. 観測量が単一のパウリ文字列のままである理由: もし ULU_LUL​ に非クリフォードゲート（T ゲートや任意の回転など）が含まれていると、ULPUL†U_L P U_L^\daggerUL​PUL†​ は多数の異なるパウリ文字列の和に展開されてしまいます。1 を得るには、多数の異なる観測量を測定して足し合わせる必要があります。しかし、この回路はクリフォードゲートのみを使用しているため、ゴッテスマン・クニルの定理により、ULPUL†U_L P U_L^\daggerUL​PUL†​ はちょうど 1 つのパウリ文字列（例: XY−ZXX Y -Z XXY−ZX）に写されることが保証されます。

  4. 数学的な保証: この構成により、期待値の計算は単純な代数的置換になります。

⟨OL⟩=⟨ψ∣OL∣ψ⟩\langle O_L \rangle = \langle \psi | O_L | \psi \rangle⟨OL​⟩=⟨ψ∣OL​∣ψ⟩

∣ψ⟩|\psi \rangle∣ψ⟩ と OLO_LOL​ を代入します。

(⟨0∣⊗nUL†)(ULPUL†)(UL∣0⟩⊗n)(\langle 0 |^{\otimes n} U_L^{\dagger}) (U_L P U_L^{\dagger}) (U_L | 0 \rangle ^{\otimes n})(⟨0∣⊗nUL†​)(UL​PUL†​)(UL​∣0⟩⊗n)

隣り合う UL†ULU_L^\dagger U_LUL†​UL​ の項は打ち消し合います（恒等演算子 III に等しくなります）。

=⟨0∣⊗nP∣0⟩⊗n= \langle 0 |^{\otimes n} P | 0 \rangle ^{\otimes n}=⟨0∣⊗nP∣0⟩⊗n

PPP は ZZZ と III のみのテンソル積であるため、P∣0⟩⊗n=∣0⟩⊗nP| 0 \rangle ^{\otimes n} = | 0 \rangle ^{\otimes n}P∣0⟩⊗n=∣0⟩⊗n となり、したがって次のようになります。

まず、クリフォードゲートのみを含む量子回路を設計します。使用するのは、単一量子ビットゲートの HHH、SSS、XXX、YYY、ZZZ と、2 量子ビットゲートの CZCZCZ です。create_brickwork_clifford 関数は、量子ビット数（num_qubits）と depth を引数に取り、指定された量子ビット数と深さを持つクリフォード量子回路を返します。

import random
from qiskit import QuantumCircuit
from qiskit.circuit.library import HGate, SGate, XGate, YGate, ZGate

def create_brickwork_clifford(num_qubits: int, depth: int = 2):
    def get_random_1q_gate():
        gates = [HGate(), SGate(), XGate(), YGate(), ZGate()]
        return random.choice(gates)

    circuit = QuantumCircuit(num_qubits)
    for layer_idx in range(depth):
        for qubit in range(num_qubits):
            circuit.append(get_random_1q_gate(), [qubit])

        # Add CZ Gate in brickwork pattern
        if layer_idx % 2 == 0:
            for qubit in range(0, num_qubits - 1, 2):
                circuit.cz(qubit, qubit + 1)
        else:
            for qubit in range(1, num_qubits - 1, 2):
                circuit.cz(qubit, qubit + 1)
    return circuit

この例の回路は 50 量子ビット（num_qubits=50）で、深さは 30、35、40、45、50、55、60、65、70 と変化します。観測量については、パウリウェイトが 2 のパウリ文字列 PPP、つまりランダムな位置にある 2 つのパウリ ZZZ 演算子から始めます。次に、evolve メソッドを使用して、各深さの回路 ULiU_{L_i}ULi​​ に対して PPP を ULiPULi†U_{L_i} P U_{L_i}^{\dagger}ULi​​PULi​†​ に時間発展させます。回路と対応する観測量を、それぞれリスト circuits_list と observables_list に保存します。

from qiskit.quantum_info import Pauli, Clifford, SparsePauliOp
import numpy as np

num_qubits = 50
depth_list = list(range(30, 71, 5))
pauli_weight = 2

# Set random seed for reproducibility
random.seed(42)
np.random.seed(42)

circuits_list = []
observables_list = []

# Choose two unique random positions for 'Z'
z_positions = random.sample(range(num_qubits), pauli_weight)

# Build the Pauli string
pauli_str = ["I"] * num_qubits
for pos in z_positions:
    pauli_str[pos] = "Z"
Z_n = Pauli("".join(pauli_str))

for depth in depth_list:
    # Generate the brickwork stabilizer circuit
    circuit = create_brickwork_clifford(num_qubits, depth)
    circuits_list.append(circuit)

    # Get Clifford object for the circuit
    cliff = Clifford(circuit)
    # Evolve Z^n by the Clifford (Heisenberg picture, default)
    conj_pauli = Z_n.evolve(cliff, frame="s")
    # Convert to SparsePauliOp
    transformed_operator = SparsePauliOp(conj_pauli)
    observables_list.append(transformed_operator)

理想的な値を得るには、スタビライザーシミュレーションを実行します。Qiskit の StabilizerState クラスを使用して、各量子回路からスタビライザー状態を作成します。このクラスは QuantumCircuit を入力として受け取り、対応するスタビライザー状態を出力します。次に、expectation_value メソッドを使用して理想的な期待値を計算します。これは設計上、各回路と観測量のペアで 1 になります。

from qiskit.quantum_info import StabilizerState

stabilizer_result_ideal_evs = []
for index in range(len(depth_list)):
    # Expectation value calculated using stabilizer group algebra, NOT matrix multiplication
    circuit = circuits_list[index]
    observable = observables_list[index]

    stab_state = StabilizerState(circuit)
    exp_val = stab_state.expectation_value(observable)
    stabilizer_result_ideal_evs.append(int(exp_val.real))

print(
    f"Ideal Results from Stabilizer Simulation:{stabilizer_result_ideal_evs}"

結果を抽出して可視化する​

ジョブが完了したら、各 PUB の結果から期待値と標準偏差を収集します。各回路の深さについて、結果にはノイズありの（抑制なしの）値 noisy_evs と noisy_stds、および AI-QEM による抑制後の値 mitigated_evs と mitigated_stds が含まれます。

次に、plot_clifford_results 関数を使用して、回路の深さに対する期待値をプロットします。プロットには次が含まれます。

  • 抑制なし: ハードウェアから返された生の期待値で、±σ\pm\sigma±σ の大きさのエラーバーとともに表示されます。

  • 抑制後（AI-QEM）: エラー抑制後の期待値で、こちらもエラーバーとともに表示されます。

  • 理想値（スタビライザーシミュレーション）: すべての深さでのノイズのない期待値 ⟨O⟩ideal=1\langle O \rangle_{\text{ideal}} = 1⟨O⟩ideal​=1 です。

import numpy as np

    depth_list,
    noisy_evs,
    noisy_stds,
    mitigated_evs,
    mitigated_stds,

    style = dict(marker="*", markeredgecolor="black", markeredgewidth=0.5)

    plt.figure(figsize=(12, 6))
    plt.errorbar(
        depth_list,
        noisy_evs,
        yerr=noisy_stds,
        label="Unmitigated",
        capsize=4,
        **style,
    )
    plt.errorbar(
        depth_list,
        mitigated_evs,
        yerr=mitigated_stds,
        label="Mitigated (AI-QEM)",
        capsize=4,
        **style,
    )
    plt.plot(
        depth_list, ideal_evs, label="Ideal (Stabilizer simulation)", **style
    )

    plt.xlabel("Circuit Depth")
    plt.ylabel("Expectation Value")
    plt.title("Clifford Circuit Simulation")
    plt.grid(alpha=0.3)
    plt.ylim(-0.2, 1.2)
    plt.legend(loc="upper left", bbox_to_anchor=(1, 1))
    plt.show()
