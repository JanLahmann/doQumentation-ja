ColibriTD による QUICK-PDE

APIリファレンスを参照してください

備考

IBM Quantum® Functions はベータ機能であり、IBM Quantum Premium Plan、Flex Plan、および On-Prem（IBM Quantum Platform API 経由）Plan のユーザーのみが利用できます。ベータ機能は変更される可能性があります。

概要​

ここで紹介する偏微分方程式（PDE）ソルバーは、Quantum Innovative Computing Kit（QUICK）プラットフォーム（QUICK-PDE）の一部であり、Quantum Function としてパッケージ化されています。QUICK-PDE 関数を使用すると、IBM Quantum QPU 上でドメイン固有の偏微分方程式を解くことができます。この関数は、ColibriTD の H-DES 説明論文に記載されているアルゴリズムに基づいています。このアルゴリズムは、計算流体力学（CFD）や材料変形（MD）を皮切りに、1～3資産のオプションに対するブラック・ショールズ方程式による定量的ファイナンスまで含む、複雑なマルチフィジックス問題を解くことができます。他のユースケースも近日公開予定です。

微分方程式を解くために、試行解は直交関数の線形結合（通常はチェビシェフ多項式、より具体的には関数をエンコードする量子ビット数を nnn としたときの最大 2n2^n2n 個）としてエンコードされ、可変量子回路（VQC）の角度によってパラメーター化されます。ansatz は関数をエンコードする状態を生成し、その状態はオブザーバブルによって評価されます。それらの組み合わせにより、すべての点で関数を評価できます。その後、微分方程式がエンコードされた損失関数を評価し、以下に示すようなハイブリッドループで角度を微調整できます。試行解は、満足のいく結果が得られるまで徐々に実際の解に近づきます。

このハイブリッドループに加えて、異なるオプティマイザーを連鎖させることもできます。これは、グローバルオプティマイザーで良い角度のセットを見つけ、その後、より細かく調整されたオプティマイザーで勾配に沿って最良の隣接角度のセットを探索したい場合に便利です。計算流体力学（CFD）の場合、デフォルトの最適化シーケンスが最良の結果をもたらします。一方、材料変形（MD）の場合、デフォルトでも良い結果が得られますが、問題に応じてさらに設定を調整し、性能を高めることもできます。

関数の各変数について、量子ビット数を指定します（変更して試すことができます）。同一の回路10個を重ね、1つの大きな回路全体の異なる量子ビット上で同一のオブザーバブル10個を評価することで、CMA最適化プロセスの中でノイズ軽減を行うか、PSR計算を並列化できます。その際はノイズ学習法を利用し、必要なショット数を大幅に削減します。

アンザッツ​

各関数をエンコードする変分量子回路は、ansatz 引数で選択します。

  • HEA は、グローバルなオブザーバブルで測定する、ハードウェア効率の良いアンザッツです。最も汎用的な選択肢です。

  • BPM-LE（Barren Plateau Mitigation, Low Expressivity）は、局所的なオブザーバブルで測定する、バレンプラトーを回避するよう設計されたアンザッツです。パラメータが少なく浅い回路で構成されるため、パラメータシフト勾配のコストを含め、最適化のコストを低く抑えられます。

  • BPM-HE（Barren Plateau Mitigation, High Expressivity）は同じ構成に従い、回路ごとのパラメータ数を増やしたものです。低表現力版では十分な精度で表現できない関数向けです。

変数ごとの量子ビット数と回路の深さは、引き続き nb_qubits 引数と depth 引数で制御します。

オプティマイザーのチェーンと誤差指標​

オプティマイザーは、optimizers 引数でステージのリストとして連結します。各ステージには、独自の手法、最大反復回数、独自のショット数を定義します。これにより、低コストでノイズの多い評価でまず探索空間を探り、最適化が収束するにつれてショット数を増やしていきます。典型的なチェーンは次の要素で構成されます。

  1. 1つ以上の CMAES ステージ（大域的で勾配不要）。解の空間の適切な領域を特定します。各ステージには、独自の shots、sigma0、popsize（個体群サイズ、つまり各世代で評価される候補の数）があります。sigma0 引数は CMA-ES の探索分布の初期標準偏差、つまり初期ステップサイズです。値が大きいと回路パラメータの空間を広く探索し、値が小さいとこれまでに見つかった最良の候補の周辺を局所的に探索します。したがって、ステージが進むごとに sigma0 を小さくすると、探索から精緻化へと移行します。

  2. LS-TRF ステージ（Least Squares - Trust Region Reflective）。この領域を探索して最終的な角度を精緻化します。psr を指定しない場合、LS-TRF は有限差分でコスト関数のヤコビアンを推定します。psr=True を指定すると、パラメータシフト則（PSR）を用いてQPU上でヤコビアンを厳密に計算します。PSR は追加の回路を必要とするため計算時間が増えますが、有限差分より高い精度が得られます。

このページで使用する誤差指標は、サンプリングした点における、解と参照解との間の二乗平均平方根誤差（RMSE）です。この関数は、平均二乗誤差（MSE）と最大絶対偏差も報告します。これらは H-DES 論文のセクション 2.6 の d2 および d1 指標に相当します。

量子ビット数は以前のバージョンより少なくなっています。回路バインディング機能は、量子ビット数ではなく、実行のQPU時間を削減します。複数の回路を並列に実行することで量子ビット数を増やすことは引き続き可能で、その場合は必要なQPU時間がさらに短縮されます。また、この function の新バージョンは、より多くの量子ビット数とより大きな問題へスケールする余地を残しています。

これらの実行の最適化ステップは次のとおりです。

  • popsize 引数は、CMAES の各世代で評価される候補の数です。
  • CMAES ステージは、コストが停滞すると早期に停止することがあります。
  • コスト評価とは、1組の回路パラメータに対するコスト関数の計算であり、ステージのショット数でQPU上で測定します。
  • CMAES の1世代は popsize 回の評価で構成されるため、CMAES の反復は世代数で数えます。
  • LS-TRF の1回の反復では、現在の点でコスト関数のヤコビアンを計算し（ここではパラメータシフト則（PSR）を使用）、1つまたは複数の試行点でコスト関数を評価します。
  • ヤコビアンには専用の回路（パラメータシフトされた回路）が必要で、これらは評価として数えません。したがって、ヤコビアンの数は LS-TRF の反復回数に等しく、一部の試行点が棄却されるため、評価回数は反復回数より多くなります。
